# motor_risco_credito
Motor quantitativo de risco de crédito bancário e contraparte, integrando modelos de PD (Probabilidade de Default), EAD (Exposição no Default) e LGD (Perda Dado o Default) para estimar perdas esperadas, analisar exposições, simular cenários de estresse e apoiar decisões de crédito por meio de Estatística, Ciência de Dados e Python.
